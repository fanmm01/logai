什么是文本数据库？

在线文本数据库（TextDB.online）是一个免费的文本数据存储和共享服务平台。用户可以通过简单的API接口存储、更新和删除文本数据。存储的文本数据可以随时下载和检索。

将数据以 application/x-www-form-urlencoded 格式发送至 textdb.online/update 即可完成文本数据的创建、更新和删除操作，支持 GET 和 POST 方法请求。

详细请求信息，请参考以下API文档。

使用须知

本服务为免费开放，旨在方便用户进行测试和学习使用。但由于其开放性，可能会受到恶意请求或攻击，导致服务不稳定甚至中断。

因此，我们建议用户仅在测试或非生产环境中使用该服务。如需将其应用于生产环境，建议使用更稳定可靠的离线版本。

我们提供售价为 300 元的离线版本，支持私有化部署。该版本运行速度更快，稳定性更高，适用于正式项目或内部系统使用。

您可以通过 demo.textdb.online 在线体验离线版本的效果。部署方式也非常简单，仅需一个文件即可完成安装和运行。

API文档

API URL https://textdb.online/update/
请求方法 GET / POST
数据编码 application/x-www-form-urlencoded
请求参数 key: 文本标识，长度为6-60位字符，仅支持以下字符：0-9a-zA-Z-_。
value: 文本数据，20万字符以下任意文本，value为空则表示删除记录。
由于没有密码鉴权保护，建议使用随机生成20位及以上的key，降低碰撞概率，减少业务风险。
请求示例 【创建/更新】https://textdb.online/update/?key=123456&value=hello-world
【删除】https://textdb.online/update/?key=123456&value=
【读取】 https://textdb.online/123456
若使用GET方式更新数据，请先进行URLEncode编码处理，建议优先使用POST方法请求。
响应参数 status: 请求处理结果，1为成功，0为失败。
data.key: 自定义的文本标识。
data.url: 文本记录的URL，可以通过该URL读取文本数据。
req_id: API请求ID。
响应示例 
{
    "status": 1,
    "data": {
        "key": "123456",
        "url": "https://textdb.online/123456"
    },
    "req_id": "131690600e2b79b47108"
}
请求限制 读取次数不受限制，每个IP每日的创建、更新和删除操作总和限制为500次。
注意事项 1. 文本记录会在没有访问和更新操作30天后自动删除，建议使用完毕后主动删除。
2. 文本数据没有访问密码保护，建议设置至少20位的key长度，或添加专属前缀，以避免因key碰撞而导致的业务风险。
3. 数据创建或更新速度较慢，请避免频繁操作。
4. 严禁存储非法数据或将平台用于非法用途！

如果文本记录不存在，则会自动创建；如果记录已存在，则会更新该记录。

创建或更新后，文本记录可以通过 https://textdb.online/[key名称] 读取，默认支持跨域请求，content-type 为 text/plain。

读取文本记录时，将始终返回200 HTTP状态码，如果文本记录不存在则响应内容为空。

TextDB.online服务搭建在Cloudflare网络上，可能会存在缓存。在创建、更新和删除文本数据时，会自动刷新缓存，因此操作可能较为耗时。请尽量减少创建和更新频率，以读取为主。

私有部署版本无需经过 CDN 中转，响应速度将更快、更高效，同时也进一步提升了数据处理的稳定性与安全性，适合对性能和可靠性要求较高的生产环境使用。
