# WebGAL 集成范围

固定基线见 `webgal-adv/engine/UPSTREAM.json`；逐文件原始 SHA256 见 `UPSTREAM_FILES.json`。本项目保留原 parser、Pixi、舞台、演出及 UI 实现，通过宿主模式扩展。

| 能力 | 状态 |
|---|---|
| 对话、旁白、语音、黑屏、头像 | 保留；额外支持自然文本编译 |
| 背景、静态及自由立绘、组合角色、差分 | 保留；mem 编译为最多五个自由立绘 |
| BGM、音效、视频 | 保留；资源绑定运行版本 |
| choose、变量、条件、label、jumpLabel | 原生模式保留；自然选择由宿主解释并校验权限 |
| changeScene、callScene、return | 原生场景保留；自然流程另由 flow 管理 |
| 动画、复杂动画、变换、过渡、滤镜、Pixi 特效 | 保留上游运行时及资源格式 |
| 已读、回顾、鉴赏 | 保留运行时；宿主阅读历史使用适配手机的独立面板 |
| 自动、快进、重播、快速存读档 | 保留上游代码，宿主界面移除底部按钮；存读档统一收进右上角菜单 |
| 浏览器全屏与设备方向 | 宿主统一全屏，包含选择与阵容弹层；不强制旋转竖屏，背景填充视口 |
| 阅读设置 | 宿主提供文字速度、字号与音量面板 |
| 标题、启动与语言选择 | 嵌入时由主应用接管；语言默认中文 |
| 原 WebGAL 编辑器预览连接 | 嵌入时关闭，使用本项目图形编辑器 |
| Live2D | 保留代码能力；未携带 Cubism SDK，取得运行库后显式启用 |
| Steam／桌面宿主功能 | 浏览器不提供桌面宿主，不能视为可用功能 |

完整原生脚本使用首行 `#!webgal`；资源放在项目对应目录。不要把 WebGAL 原生变量与 flow 控制语句混写为同一种语法。自然模式支持常用原生命令行；外部选择使用 chos 和 flow。

构建采用独立 npm workspace；parser 使用同一源码的 TypeScript 声明生成与 esbuild 打包，规避上游 Rollup TS 过滤器在 Windows 的路径兼容问题。原 parser 测试继续执行。
