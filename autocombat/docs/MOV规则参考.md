# MOV 与主动作数规则参考

更新日期：2026-11-15。

## 统一公式

```python
主动作数 = max(1, (有效MOV + 1) // 5 + 额外行动数)
```

`//` 为向下取整。未设置“额外行动数”时兼容读取“回合行动数”。设置“无主动行动”的单位直接返回 0，不套用最低 1 动。

| 有效 MOV | 基础主动作数 |
| --- | --- |
| 0～8 | 1 |
| 9～13 | 2 |
| 14～18 | 3 |
| 19～23 | 4 |
| 24～28 | 5 |
| 29～33 | 6 |
| 34～38 | 7 |

之后每增加 5 MOV 增加 1 动，无上限。额外行动数在向下取整之后相加，最后应用最低 1 动。

## 变身与飞行

- 变身基础 MOV 收益从 +2 改为 +3，解除变身恢复原值。
- 魔法少女仅在变身后启用飞行，包括飞行的 MOV+8 和近战交互；解除变身后停止生效。
- 飞行召唤物出生即有飞行，不要求执行变身。飞行只生效一次，不重复叠加。
- 当前角色变身前基础 MOV 为 7 或 8，无额外行动数、未受加速时由统一公式得到 1 动；加速后仍按公式计算，并非强制锁定 1 动。

有效 MOV 的结算顺序沿用原规则：基础 MOV 加普通增减及领域修正，再加飞行的 8 点，最后乘减速倍率、向下取整且不低于 0；冰冻归零规则保留。

## 召唤物

所有具备基础 MOV 的召唤物模板统一 +3，包括三合一、小雪人、影之克隆与血液长枪。随机召唤物入口没有独立 MOV，使用被选中的模板。虚假之月等“无主动行动”单位仍为 0 动，即使其 MOV 增加。

| 模板 | 原 MOV | 新 MOV |
| --- | --- | --- |
| 三合一、生灵 | 10 | 13 |
| 使魔 | 6 | 9 |
| 朱雀、蜂鸟 | 11 | 14 |
| 玄武 | 3 | 6 |
| 藤蔓、龙虎、影之克隆 | 8 | 11 |
| 小雪人 | 5 | 8 |
| 虚假之月、血液长枪 | 0 | 3 |

## 与旧版的关系及限制

本次采用用户最终确认的“变身 +3”，不是此前讨论的“变身 +5”。因此不承诺所有角色在所有 MOV 增减状态下动作数完全不变。

召唤物基础 MOV 增加 3，恰好抵消公式阈值增加 3；在没有减速、冰冻等改变最终 MOV 的非加法效果时，保留原动作数，包括再加 MOV+5、飞行+8 及其组合。变身角色相对旧版仅增加 1 MOV，因此部分临界状态可能减少 1 动。例如余烬原有效 MOV 为 22 时，旧版为 5 动；对应新版 MOV 为 23 时为 4 动。

MOV 增加同时影响移动距离及相关 MOV 判定，不仅影响主动作数。血天使与“巨人”已有飞行，不能再叠加第二份飞行 MOV+8；当前模板没有独立的 MOV+8 增益。
