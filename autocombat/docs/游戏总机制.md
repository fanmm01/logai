# 游戏总机制

本页按战斗流程整理公共术语，每个条目也用于角色卡中的“释义”。同义名称共用完整解释。角色专属的数值、门槛、触发次数及例外以当前角色百科为准，可在页末的专属机制索引查看。

## 1. 行动与时机

### 回合 / 轮 / 轮首

- 一轮包含先攻表中各单位的行动；日志中的“第几回合”表示全场轮数，不表示某个角色出手了几次。同一轮可以使用多个主动作。
- 轮首是进入新一轮时的统一结算点，会推进持续效果、领域、濒死检定和资源恢复，并重置本轮行动与移动额度。使用一次技能不会单独推进一轮。
- “每轮一次”“每次行动一次”“每次施放一次”是不同的次数限制；角色的行动开始、结束与轮首触发应分别阅读。

### 先攻 / 敏捷

- 先攻决定行动次序。开战以敏捷进行 D100 检定，先比较成功等级，再比较敏捷，最后比较骰点；成功等级高、敏捷高、骰点低者优先。
- 主动作多不表示先攻更早。召唤物加入或代表更换时会维护先攻表；界面中的当前行动者才是本次操作所属单位。

### 主动作 / 主动 / 行动额度

- 主动作供普通攻击、主动技能等使用。技能必须允许当前动作类型，不能将所有主动技能任意改为附加动作。
- 每轮主动作数为 `max(1, floor((有效 MOV + 1) / 5) + 额外行动数)`；明确设置“无主动行动”的单位为 0。控制状态仍可禁止使用已有额度。
- 没有额外行动数时，有效 MOV 为 0–8、9–13、14–18、19–23，分别获得 1、2、3、4 个主动作，之后继续递增。
- 普通增减益导致上限变化时，可同步调整剩余主动作；仅进出领域不会补发或追回本轮已经分配的动作。

### 附加动作 / 附加

- 与主动作分开记录的额度，通常每轮 3 次，供允许附加时机的技能、食用或给予物品等使用。
- 附加动作仍须满足技能时机、费用、冷却和控制状态要求。召唤组成员共用组的动作池，不是每名成员各有一套。

### 行动力 / MOV / 有效 MOV / 额外行动数

- 行动力参与行动次数和部分攻防奖惩骰计算；MOV 是移动与行动计算使用的属性名，默认与行动力关联，某些单位可单独设置移动力。
- 用于主动作数的有效 MOV 依次计算基础值、属性与领域修正、飞行加成，再应用减速倍率，向下取整且不低于 0。召唤物优先使用自身 MOV。
- 额外行动数直接加在主动作数公式中，不是增加同等数值的 MOV。角色卡数值表的基础值不包含临时技能、被动和状态加成。

### 移动 / 移动力 / 自动接近 / 锚点

- 移动力是本轮距离预算，同一单位的多次行动共享已使用距离；获得更多主动作不会重置移动预算。
- 显式移动须满足边界、占位、障碍与剩余距离要求。攻击可能先自动接近；距离不足时也可能已经消耗部分移动力。
- 锚点是本轮开始的位置。相应自动退回流程使用剩余移动力尝试返回，接近和退回共用预算，不保证回到原处。
- 不能移动不必然禁止原地攻击：已经在射程内时，仍按攻击及控制状态限制判断。

### 飞行

- 飞行给有效 MOV 增加 8，角色还可能有其他行动力修正；不是每次行动额外获得一笔独立的 8 格移动预算。
- 飞行也影响近战可攻击性，地面近战攻击飞行目标可能受限；远程技能与专属例外看各自规则。

### 被动 / 初始化

- 被动在开战或对应形态初始化时自动尝试发动，不是每使用一个主动作就重放一次。被动也可能需要支付费用。
- 隔离可阻止被动初始化或暂停来源效果；切换阶段时是否重建、清理或保留，以该能力为准。

### 受击反应 / 受伤触发

- 受击反应是角色能力在受到攻击等条件下自动触发的专属效果，与选择闪避、反击、格挡分别处理。
- “受到攻击”“命中后”“护盾吸收后仍有伤害”“实际损失 HP”是不同条件。多段攻击按各段及能力的次数限制检查。
- 专属 MP 或资源在触发时支付；普通防御免费不免除这些专属费用。

### 冷却 / CD / 每场一次

- 冷却是再次使用技能前须等待的轮数，剩余值大于 0 时不能使用，随轮次推进递减。冷却和效果持续时间分别记录。
- 每场一次、累计使用上限与阶段封锁另行记录；回复资源、效果到期或目标死亡通常不会重置这些限制。

### 阶段 / 形态 / 武器

- 决定可用技能版本、普通攻击资料和专属被动。同名技能在不同阶段可有不同费用、效果和要求。
- 切换时按角色规则清理或保留效果、初始化被动，不表示必定回满生命或重置所有次数。
- 阶段 99 是保留能力，不开放常规战斗使用。角色阶段不能与全场的准备阶段混为一谈。

### 变身 / 解除变身 / 等级 / 攻击次数

- 角色数值表区分变身前与变身后，战斗面板显示当场实际值；表中攻击次数指每轮主动作数，不是一个技能的段数。
- 标准变身按等级放大 HP、MP，行动力增加 3、体格增加 1，适用的战斗技能与闪避增加 20、最高加到 80；原值已高于 80 时不会降低。专属弓术与已预先变身的单位按各自加载规则处理。
- 解除变身恢复原始属性资料；角色的形态切换和标准变身属于不同流程，不可互相推断资源重置或次数返还。

### 当前行动者 / 结束行动

- 当前行动者是先攻表轮到的单位；选中目标或查看角色不会转移行动权。结束行动会放弃本次剩余操作并推进次序。
- 技能正在等待防御反应时，须先完成反应，后续段数与派生效果才继续结算。

## 2. 技能费用

### MP / 魔力 / 技能费用

- MP 是魔力资源，用于技能起手、被动初始化或专属反应。按基础费用、费用骰或专属公式支付；缺省或零基础费用按 0 MP 处理。
- 多段攻击每次施放只付一次起手费用，内部派生效果不重复收取同一笔施法费；独立能力被触发时仍按自身规则付费。
- MP 不足不能发动相应技能。召唤物使用自身 MP，不自动向主人借魔力；其攻击招式与同名主动法术可能费用不同。

### 普通攻击 / 免费动作

- 普通攻击使用角色或当前武器的攻击资料，并消耗对应主动作；借用某技能的伤害骰不等于主动施放该技能。
- **普通攻击、普通闪避、普通反击和常规格挡不新增 MP 费用。** 免费不表示不消耗主动作、移动或专属触发费用。
- 主动使用命名技能发动同类攻击时，仍按该技能付费。普通斗殴及明确声明 0 MP 的召唤物攻击招式免费，主动法术另算。

### 费用减免 / 费用修正 / 向下取整

- 普通技能先应用百分比费用修正并向下取整，再加固定修正，最终最低为 0 MP。例如基础 5 MP、降低 50%、再减少 1 MP，费用为 `floor(5 × 0.5) - 1 = 1 MP`。
- 奖励骰不减少费用骰结果。血术等专属公式可有自己的费用下限、分摊及取整规则，不能直接套用普通 MP 公式。

### 魔能消耗百分比 / 魔能消耗加值

- 分别是 MP 费用的百分比与固定修正字段，正数增加费用、负数减少费用；“加值”也可由骰子决定。
- 它们修改费用计算，不是给角色回复魔力，也不自动修改 HP、SAN 或专属资源的消耗。

### 准备阶段

- 正式轮次前的站位与允许的准备操作时段，不能视作战斗中的额外免费回合。
- 准备阶段保留技能原有的非 MP 资源豁免，MP 仍按正常技能费用支付；还须符合准备流程允许的能力与目标要求。

### SAN / 理智 / 专属资源

- SAN 表示理智，和 HP、MP 分别记录；消耗 SAN 不自动改为消耗 MP。
- 血液、月能、金环、极限值、灵感等是独立资源，各自有获取条件、上限、用途与跨阶段保留规则。
- 技能可同时消耗多种资源，MP 足够不能代替血液、HP、SAN 或其他门槛。直接支付 HP 也不必然属于攻击伤害。

### 起手 / 提前拒绝 / 退费

- 起手表示技能通过前置检查并开始执行，此时支付费用，可能登记冷却、次数或吟唱状态。
- 无合法攻击目标、纯召唤名额已满等提前拒绝，不扣本次技能费用；混合效果技能须检查其余效果是否仍可执行。
- 已起手的攻击即使落空、被闪避、被反击或全被护盾吸收，也不退费。吟唱取消与中断另看专属代价。

## 3. 检定与骰子

### D100 / 百面骰 / 骰点

- D100 产生 1–100 的整数，通常越低越有利。`D100=32/60` 表示骰点 32、技能值 60，不表示伤害为 32。
- 十位与个位均为 0 表示 100。攻击先计算成功等级，再进入防御对抗；初始检定成功不保证最终造成伤害。

### 技能值 / 成功率 / 斗殴 / 写作

- 技能值是检定比较数值，如斗殴、闪避、格挡、写作；攻击可指定固定成功率或读取角色当前技能值。
- 指定属性修正只改变对应项目，“闪避 -10”不同时削弱斗殴。技能值修正改变门槛，奖励骰改变掷骰选择，两者不同。
- 斗殴常用于近战，武器可改用剑、鞭、爪击等技能。写作可用于幻造兵武的伤害调整，不是直接把写作值当伤害。

### 技能奖励骰 / 技能惩罚骰 / 技能值倍增 / 伤害成功率加减

- 技能奖惩骰按指定技能或骰子设置参与 D100 净额，不改变伤害骰。技能值倍增先改变检定门槛，再用于成功等级判定。
- 伤害成功率加减调整攻击检定使用的数值，不直接加减最终伤害；同名属性与全局修正应按实际适用范围区分。

### 暴击率 / 暴击值

- 这两个辅助字段修改极难成功的判定门槛：暴击率改变技能值的门槛比例，暴击值追加固定门槛修正。
- 它们不是额外再掷一次暴击骰，也不等于把所有攻击变为大成功；1 和 96–100 等固定判定仍按成功等级规则处理。

### 普通成功 / 成功 / 困难成功 / 极难成功 / 大成功 / 失败 / 大失败 / 成功等级

- 普通、困难、极难、大成功对应等级 1、2、3、4；失败为 -1，大失败为 -2。日志里的“成功”通常指普通成功，也可泛指正等级结果。
- 技能值为正时：1 必为大成功；96–100 必为大失败；其余先检查是否超过技能值，超过则失败。通过门槛后，2–5 为大成功，通常不超过技能值五分之一为极难、不超过一半为困难，其余为普通成功。
- 极难门槛可被专属修正改变：基础比例 20%，比例修正后限制在 1%–50%，再加固定门槛修正。技能值 60、无修正时，1–5 大成功、6–12 极难、13–30 困难、31–60 普通、61–95 失败、96–100 大失败。
- 技能值不大于 0 时使用特殊规则：1–5 大成功、96–100 大失败、其余失败。很高的技能值也不取消 96–100 的大失败。
- 防御会改变有效攻击等级。大失败不是固定“自己扣血”，后果要结合攻防、吟唱或专属能力。

### 奖励骰 / 惩罚骰 / b / p

- 保留同一个个位，额外掷十位；奖励骰选较低、惩罚骰选较高的完整 D100 结果，不是把两次完整 D100 相加。
- `b`、`b2`、`b3` 分别表示 1、2、3 颗奖励骰，`p`、`p2`、`p3` 为惩罚骰。适用来源先相互抵消，再将净额限制在最多 3 颗。
- 2 颗奖励骰与 1 颗惩罚骰合并为 1 颗奖励骰。个位为 0 时，十位 0 对应 100，仍视作最差结果。

### 全 D100 奖励骰 / 全D100检定奖励骰 / 攻击奖励骰 / 攻击惩罚骰 / 反应惩罚骰

- 全 D100 奖励骰作用于该单位适用的攻击、防御、体质豁免及其他 D100 检定，每次检定合并一次。
- 攻击奖励骰、攻击惩罚骰只作用于对应攻击；反应惩罚骰作用于目标防御。限定技能名的修正按实际攻击或反应技能匹配。
- 伤害、治疗、制造数量和资源费用等数值骰不属于 D100，不受全 D100 奖励骰影响。体质等豁免也不使用只限攻击的修正。

### 行动力优势

- 普通攻防路径中，攻方行动力至少比防方高 5 且自身大于 10 时，攻方获 1 颗奖励骰；否则若防方行动力大于 10，防方反应获 1 颗惩罚骰。
- 此处比较行动力，不是剩余主动作或伤害骰优势。特定法术可另设防御奖惩，以实际攻击规则为准。

### 伤害骰 / 数值骰 / 满值 / 固定值

- `2d6+3` 表示掷两颗六面骰再加 3，范围 5–15；`1d4+db` 还须解析当前体格伤害加成。满值是表达式能得到的最大值。
- 伤害、治疗、费用和数量骰分别按其用途结算，不按 D100 成功等级判断。固定值如 `6` 无需随机掷骰。
- 满值与固定值都不等于最终 HP 损失，后续倍率、减伤与护盾仍可能改变结果。

### 伤害骰优势 / 伤害骰劣势 / 优势 / 劣势

- 在需要随机掷伤害时，优势掷两次取高，劣势取低；同时存在时互相抵消。
- 困难成功的常规伤害本身掷两次取高；极难、大成功用对应满值规则，不再简单重复普通掷骰方式。多个“取高”不表示无限重掷。
- 致死骰优势与劣势使用独立规则，不能由伤害骰优势推断。

### 贯穿 / 非贯穿 / 等级伤害

- 贯穿是高成功等级伤害公式的标记，不表示忽略护盾、格挡、射程或命中检定。
- 常规伤害路径中，普通成功掷伤害，困难成功掷两次取高；极难成功时，贯穿为满值加一次掷骰，非贯穿为满值。
- 大成功时，贯穿或攻击骰点为 1 通常取满值两倍；非贯穿且骰点不是 1 时取满值加一次掷骰。防御后的有效等级可能低于初始等级。
- 特殊固定效果、格挡承伤和持续伤害可走独立路径，不能对所有数值一律套用等级伤害。

### 豁免 / 体质 / 体质检定

- 豁免是为抵御或维持状态进行的检定，例如进入濒死时的体质检定；所需成功等级由触发条件决定。
- 体质豁免使用体质值，全 D100 奖励骰可参与，仅限攻击的奖励骰不能移用。成功不必然回复生命。

## 4. 防御与多段攻击

### 防御反应 / 可反应 / 不能闪避 / 不能反击

- 闪避、反击、格挡分别受攻击允许方式、角色属性、状态和盾牌限制，界面只提供当次可选方式。
- 不能闪避只关闭闪避，不能反击只关闭反击；攻击自身仍须检定。没有反应不代表必定命中。
- 普通防御不调用技能施法扣费，专属反应另算。部分盾牌召唤物可对不可反应法术格挡，但不能推广至所有单位。

### 闪避 / 有效攻击等级

- 以当前闪避值检定，成功时从攻击等级减去闪避等级；剩余不大于 0 则未命中，大于 0 则按剩余等级继续。
- 例如攻击极难 3、闪避困难 2，剩余为 1，仍按普通成功命中；双方普通成功则剩余为 0，完全避开。
- 普通失败不减等级。闪避大失败提高有效攻击等级：原攻击为普通失败 -1 时加 2，其余加 1，最终限制在 -2 至 4。

### 反击 / 互命中

- 用防方可用的近战技能与对应伤害资料比较成功等级。防方正等级更高则反击命中并化解原攻击，攻方正等级更高则原攻击命中。
- 相同正等级会互命中，双方各自结算伤害；双方都没有正等级则无人得手。反击成功不保证无伤。
- 防方反击大失败可提高攻击等级；攻方大失败可将反击等级提高 1，最高为 4。攻击失败时也可能被反击。
- 攻方不可选中时，反击可以化解攻击但不一定能伤到攻方；主动使用命名攻击技能仍需按技能付费。

### 格挡 / 盾牌 / 盾牌耐久 / 代受伤害

- 要求角色允许格挡、有可用格挡技能，并有盾牌耐久或可代受伤害的召唤物。格挡成功等级用于抵消攻击等级。
- 抵消到不大于 0 后进入盾牌承伤：可先消耗普通护盾，再扣盾牌耐久，超出的伤害仍可扣 HP。格挡成功不保证完全无损。
- 剩余攻击等级仍大于 0 则突破盾牌，继续正常结算。格挡大失败的等级调整与闪避相同。
- 代受伤害表示指定召唤物承担该路径的伤害，先消耗它的盾牌耐久，再可能损失它的生命，与给原目标增加护盾不同。

### 失败攻击仍可反应

- 当前流程允许失败或大失败的攻击进入防御反应：成功反击可能伤到攻方，闪避或格挡大失败可能使原本普通失败的攻击命中。
- 因此检定失败不等于整次攻防一定无伤；关闭相应战斗设置的流程可在失败后直接结束。

### 多段攻击 / 段数 / 连击 / 每次施放 / 每次命中

- 一次施放内按顺序处理多次攻击，各段分别检查命中与防御。某段失败不取消其余段，目标倒下后停止对其尚未结算的攻击。
- 默认围绕所选目标，只有明确允许时才分散或溅射到其他目标；通常只占一次施放动作与起手费用。
- 每次施放、每段、每次命中、实际失血后的触发是不同口径，资源收集、同目标增伤与叠层应按具体规则计数。

## 5. 伤害、护盾与回复

### HP / 体力 / 生命 / 生命上限

- HP 是战斗生命，体力是角色资料中的生命属性。当前值与上限分别记录，满值不代表现在还剩多少。
- 伤害、治疗、直接支付 HP 与护盾从不同路径影响生命。实际生命损失最多为扣除前剩余生命，超过部分可另记为溢出伤害。
- HP 为 0 后按濒死与死亡流程处理，普通治疗不能把所有已经死亡的单位拉回战场。

### 伤害 / 直接伤害 / 实际生命损失 / 减伤 / 易伤

- 常规直接伤害先按有效成功等级计算伤害骰，再处理倍率、固定修正、专属减伤、护盾，最后扣生命；独立效果可有不同顺序。
- 易伤增加受伤，减伤降低受伤。百分比倍率、固定加减、伤害上限与护盾容量分别计算，不是同一种修正。
- 命中、护盾吸收前伤害、吸收后的结算伤害、实际生命损失是不同数值。例如伤害 10、护盾吸收 8、原有 HP 为 1，实际只损失 1 HP。
- 火鼠裘、血术等按各自触发条件处理；不能从原始伤害直接推算吸血、储血或受伤收益。

### 护盾 / 容量 / 护盾吸收

- 护盾是在生命受损前吸收伤害的容量，不增加生命上限。容量 8 吸收伤害 10 后耗尽，剩余 2 继续结算。
- 多个独立护盾分别保留容量，同名护盾的叠加、刷新或覆盖由定义决定；到期、来源失效或阶段变化也可能清理护盾。
- 普通护盾不需要选择格挡，盾牌耐久则走格挡流程。伤害全被吸收时，依赖实际 HP 损失的能力通常不触发。

### 伤害免疫 / 免疫一次伤害 / 伤害上限 / 减伤阈值

- 免疫一次伤害按该能力对应的伤害事件消耗次数，不表示整个多段技能期间持续无敌。
- 伤害上限意指单次伤害限额，减伤阈值意指按门槛处理伤害；当前公共引擎仅登记这两个辅助类型名称，未统一应用相应减伤逻辑。自定义条目只声明字段，不能据此认定已经生效，须有对应专属实现。
- 直接伤害、持续伤害是否消耗同一次免疫，要看效果路径；免疫伤害不自动免除技能费用、控制状态或其他代价。

### 受到伤害百分比 / 造成伤害百分比 / 受到伤害加值 / 伤害骰加值 / 伤害骰倍增

- 常规路径将适用的造成伤害与受到伤害百分比相加后形成倍率；例如造成伤害 +20%、受到伤害 -10%，对应倍率为 1.1，不是分别相乘。
- 伤害骰加值将额外骰子并入表达式；伤害骰倍增对所得数值应用倍率。受到伤害加值是受方固定修正，在护盾前结算，负数可减伤。
- 百分比、骰子、固定值按所在步骤处理和取整；同目标倍率、火鼠裘等专属顺序另算。

### 消耗hp转为消耗mp / 生命转魔力消耗

- 对应辅助效果生效时，生命扣除可先由当前 MP 等量承担，魔力不足的剩余部分再损失 HP。
- 这是生命变动路径的拦截，不是增加护盾容量，也不是减少技能起手 MP 费用。直接支付生命与受伤触发仍须按该次实际结算判断。

### 吸血 / 生命吸取

- 满足技能条件后为施法者回复生命的能力，比例、基数、费用与次数由技能决定。
- 有的按护盾吸收前伤害，有的按目标实际生命损失计算；血刃和月相吸取还可能有独立上限。相同比例不保证回复量相同。
- 通常不超过施法者生命上限，且须满足存活条件；符合月亮链接等能力时，溢出可转存，不自动变成护盾。

### 治疗 / 回复 / 恢复 / 溢出回复

- 治疗通常指恢复 HP，回复也可指 MP、SAN 等；各资源分别计算上限和修正，不能互相替代。
- 即时回复在技能结算时发生，持续、延迟与领域回复按指定时机结算。多个目标通常分别掷骰并应用修正。
- 超过上限而未加入当前资源的部分为溢出回复，月亮链接等能力可在满足来源和关联条件时接收，没有能力时不自动储存。
- 濒死急救与死亡复活分别判定；生命已满不表示同技能的 MP 回复或其他效果必然无效。

### hp回复百分比 / hp回复加值 / mp回复百分比 / mp回复加值 / 自然回魔

- HP 与 MP 的回复百分比、固定加值分别记录，修改对应回复路径，不改变资源上限；某些专属补满、吸取和直接设值可使用独立公式。
- 自然回魔是在轮次结算中的魔力恢复，与主动技能和共享池取物分开处理；不能默认每个单位、每种专属资源都有同样的自然恢复。

### 持续伤害 / DOT / 持续回复 / 延迟回复

- 持续伤害是登记后在后续轮次生效的伤害，例如灼烧或部分冰冻效果，不是每次目标行动都重新施放技能。
- 通常在轮首按记录的骰子结算，不为每次跳伤重新进行原攻击的 D100 命中和防御反应；护盾等按其路径处理。
- 持续回复按每次效果恢复，延迟回复可将总量分配到后续数轮。最后一跳、刷新及是否绑定来源要同时读持续时间和专属说明。

### 致死骰 / 即死 / 致死骰优势 / 致死骰劣势

- 部分伤害路径在普通扣血外进行的专属判定，不是所有攻击都有，也不是大成功的另一个名字。
- 常规相关路径要求启用致死且伤害表达式期望值大于 6，骰面通常为目标当前 HP 的两倍、至少 2。普通攻击与法术的门槛和生命处理不同，以技能与日志为准。
- 当前致死骰优势取两次中较高结果，劣势取较低结果；不能套用伤害骰或 D100 奖励骰的直觉。
- 即死仍进入该路径的生命、濒死与死亡处理，不表示无视所有替身、救援或复活。

### 溢出伤害 / 同归于尽 / 胜负判定

- 溢出伤害是扣血超出目标剩余 HP 的部分，与溢出回复不同，可用于最终阵亡和双方同时倒下的记录与判定。
- HP 为 0 不代表整场立即结束，须完成当前动作、救援和双方存活检查。
- 最大轮数后的胜负、平局与淘汰处理由模式决定；召唤物与参赛角色在超时统计中可能不同，以当场赛制和结果面板为准。

## 6. 持续效果、领域与范围

### 持续时间 / 剩余轮数 / 生效次数 / 轮首结算

- 通常按全场轮数推进，同一轮多次行动不会额外减轮数。剩余期限不应直接等同于还会跳几次伤害或治疗。
- 领域可在施放时立即结算，或只在之后轮首结算，有的另设轮首结算次数。持续 3 轮不必然总共生效 3 次。
- 同时检查是否立即生效、何时减轮数、到期轮是否包含最后一跳、是否另设次数；专属计数器与普通增益可有不同规则。

### 增益 / 减益 / 状态 / 默认延续

- 增益和减益增强或削弱技能值、倍率、费用、移动与防御等，控制状态还可直接禁止操作。
- 普通效果到期解除；声明默认延续的增益可在倒计时结束后继续生效，直到来源清理、阶段变化或专属规则移除，不是所有归零效果都删除。
- 角色属性中的“状态”也可指本场抽取的发挥状态值，与禁锢、击晕等控制状态不是同一字段。

### 赛季状态 / 发挥状态 / 幸运

- 发挥状态为本场生成的 0–100 状态值，AI 可据此调整决策中的随机性；赛季状态设置影响抽取倾向，不保证每场固定等于该数值。
- 幸运是角色基础属性，不直接等于命中率或奖励骰；只有明确读取幸运的检定才按该属性判断，不能据幸运高低推断所有掷骰结果。

### 领域 / 光环 / 随身领域 / 固定领域 / 来源存活绑定

- 领域按区域与阵营过滤作用对象；光环通常是随来源移动的范围效果。随身领域跟随来源，固定领域保持创建位置。
- 范围内属性增减通常随进出立即生效或解除，已授予的独立护盾和状态按自身期限处理，不一定随离开范围消失。
- 来源存活绑定要求来源满足存活与关联条件，主人死亡、隔离或阶段清理可暂停或移除效果。射程与覆盖半径分别计算。

### 叠加 / 刷新 / 覆盖 / 层数

- 叠加是多个效果或层数共同贡献数值，刷新是保留一份并更新期限，覆盖是以新记录替换旧记录。
- 同名不保证可叠加，不同来源也要看定义；同名蛋糕增益通常刷新而不重复累计。
- 层数是专属计数，可有上限、循环、衰减和阈值爆发，如冰冻八层循环；层数不等于持续轮数。

### 沉默 / 缴械 / 禁锢 / 击晕 / 减速 / 冰冻

- 沉默禁止主动技能与附加时机的主动施法，不直接禁止普通攻击和被动；缴械禁止普通攻击，本身不禁止全部法术。
- 禁锢禁止显式移动和自动接近，已有合法射程时仍可尝试原地攻击。减速降低有效 MOV，跨过公式门槛时可影响主动作数。
- 击晕禁止主动作、主动施法、移动及闪避、反击、格挡；部分食用、给予和结束操作由独立流程允许。特定击晕带伤害性目标保护，普通击晕不能一律视为无敌。
- 冰冻是专属叠层系统，部分层数可令有效 MOV 为 0 并限制移动，伤害、减益与恢复须查角色冰冻条目，不能等同于通用击晕。

### 隔离 / 链接 / 来源

- 隔离可阻止被动初始化、暂停相关领域及来源效果，处于隔离的单位也可能不接受对应领域影响；不是删除全部角色数据。
- 已记录的专属资源、触发次数和累计召唤账本不会仅因隔离清空，解除后能否恢复要检查原效果与来源是否仍有效。
- 链接与指定来源关联，例如月亮链接；并非同阵营天然共享。来源死亡、离场或隔离时，增益与资源流转须重新检查条件。

### db / 体格 / 体格伤害加成

- `db` 是伤害表达式中的体格伤害加成，优先读角色配置的 db，未配置时按体格资料解析，不是 D100 奖励骰。
- `1d4+db` 须先解析当前 db 再组成伤害，不能把 db 固定当作 1 点或直接当体格值。武器、阶段、附魔与状态可改变实际普通攻击资料。

### 射程 / 作用半径 / 距离 / 格 / 近战 / 远程

- 常规格距取横向差与纵向差的较大值，斜向相邻也为 1 格；横向相差 3、纵向相差 2 时距离为 3。
- 射程限制选择攻击目标或落点有多远，作用半径限制来源或中心覆盖的区域。目标在射程内不表示所有队友都在覆盖范围内。
- 普通近战通常以 2 格为基础，远程和特定技能读各自资料；飞行、不可选中、落点占用和专属几何区域还可施加限制。
- 开启统一射程设置时，通过统一查询的目标选取可改为 99 格，领域半径及其他独立攻击区域和距离要求仍按原规则计算。

### 目标 / 自身 / 友方 / 敌方 / 单体 / 群体 / 随机目标

- 过滤条件分别指定自身、友方、敌方、召唤物及阵亡单位等对象，“友方”是否包含自身看技能设置。
- 单体处理选定对象，群体按范围展开，随机目标从合法候选集合抽取，不表示必定选择生命最低者。
- 同一技能的多个效果可以使用不同目标过滤，选定目标不必然同时承受每个治疗、增益或伤害效果。

### 不可选中 / 不可指定 / 伤害性目标保护

- 限制单位被作为对应攻击目标，可由护卫召唤物存活或自身特性维持，与护盾和减伤不同。
- 伤害性目标保护可只阻止伤害攻击，不阻止治疗或增益；不可选中的攻方仍可能被化解攻击，却不受到反击伤害。
- 范围效果、持续伤害与友方辅助按自身检查处理，不可选中不能直接理解为对全部规则免疫。

## 7. 召唤、阵亡与复活

### 召唤 / 召唤物 / 主人 / 召唤模板

- 由技能创建的独立战斗成员，按模板拥有自身 HP、MP、技能、反应方式、持续时间与归属主人，不自动继承主人的全部属性和被动。
- 只传递明确声明的链接、附魔或资源共享。攻击招式与主动法术可使用不同费用：朱雀爪击与俯冲攻击、玄武盾击与盾牌冲撞攻击、三合一攻击招式可为 0 MP，同名主动法术仍付费，小雪人按雪球与小雪带的专属费用结算。
- 主人死亡或持续到期时按关联规则退场；召唤物生命归零通常直接进入阵亡流程，不等待普通角色的濒死救援。

### 同时存活上限 / 累计召唤上限 / 唯一召唤 / 可用位置

- 同时存活上限限制当前在场数量，死亡或退场可释放名额；累计召唤上限记录本场已创建数量，死亡不会返还次数。
- 唯一召唤还可能登记本场使用记录，不因场上归零就必定允许重建。
- 可用位置是实际落地空间要求，名额足够而没有合法位置也可能失败。群组与单体的占位规则不同。

### 召唤组 / 代表成员 / 共享行动 / 共享位置

- 同类召唤组可共用一个先攻入口、位置与动作池；代表只是先攻表和棋盘的展示入口，不表示组里只有一个单位。
- 一次组动作扣一次共享额度，再逐一执行当时存活成员，各自检查生命、控制、MP 和目标；新成员不插入已开始的行动快照。
- 成员各自保留生命、状态与资源。代表死亡可由存活成员接替，不重置整组动作或累计召唤账本。

### 濒死 / 死亡 / 阵亡

- 默认启用濒死系统：参赛角色 HP 降至 0 时，先查替身等专属救援，再尝试体质豁免；成功可进入濒死，失败则按死亡和可用救援处理。
- 濒死尚未最终死亡，但不能正常行动。此后轮首体质要求逐步提高：第 1 次普通、第 2 次困难、第 3 次极难、第 4 次起大成功，失败则死亡。
- 召唤物通常不进入濒死；关闭濒死系统的对局可直接按死亡处理。最终死亡记录墓地并触发关联退场，不能仅凭 HP 为 0 认定已经最终阵亡。

### 急救 / 自救 / 自动食用 / 濒死溢出伤害

- 急救针对仍濒死的单位，治疗先抵消濒死记录中的溢出伤害，剩余治疗才能恢复正数 HP 并解除濒死。例如溢出 3、治疗 5，救回后为 2 HP；治疗恰好为 3 时仍未脱离濒死。
- 携带个人生命蛋糕的单位可立即自动食用，直到脱离濒死或耗尽可用蛋糕，不表示自动从全队共享池无限取用。
- 明确具有领域急救的治疗领域可走优先救援流程，不是任意回复都自动有相同资格。已经死亡的单位需要复活。

### 复活 / 墓地 / 复活窗口 / 复活次数

- 墓地保存最终阵亡记录。复活须满足目标类型、死亡时间窗口、累计次数、资源和合法落点等要求。
- 主人死亡导致的关联退场与独立被击杀可能资格不同；墓地里有名字不表示一定能复活。
- 成功后按专属规则恢复生命、位置、形态和允许保留的资源，物品、召唤账本、每场次数不必全部重置。普通治疗不能替代复活。

## 8. 制造物与吟唱

### 制造物 / 制造 / 制造时间 / 制造数量

- 制造能力生成个人库存或队伍共享池中的物品，可有等待时间、数量骰、持续时间及可用对象限制。
- 制造时间是就绪前等待，不等于食用后的增益期限；制造数量是份数，不是治疗掷骰次数。
- 制造、给予与食用是不同操作，分别检查时机、动作和库存；施法成功不表示物品必定立即可用。

### 蛋糕 / 生命蛋糕 / 魔力蛋糕 / 增益蛋糕

- 生命蛋糕回复 HP，魔力蛋糕回复 MP，增益蛋糕提供模板声明的限时效果；回复量、份数和期限读取当前角色与物品资料。
- 主动食用通常先消耗个人库存，再取合法共享物品；同种增益通常保留一份并刷新时间，不因连续食用无限叠加。
- 濒死自动食用个人生命蛋糕与主动食用共享物品属于不同流程；部分制造物还限定使用者、给予或食用目标。

### 个人库存 / 共享池 / 共享制造物池 / 给予 / 食用

- 个人库存属于指定单位，共享制造物池属于其队伍，仍须符合物品权限和目标要求，不表示两队都能取用。
- 给予将合法物品交给目标，食用消耗一份并结算效果；看见库存不表示无须动作即可消耗。
- 死亡后的保留与复活后的物品恢复按专属流程处理，不能把库存数量当作自由转移的 MP。

### 吟唱 / 吟唱回合 / 续唱 / 释放

- 从起手到技能完成之间的等待或持续施法状态，通常起手付费，再按轮数、动作和完成条件释放。
- 一般倒计时吟唱与血术主动续唱不同；血术可要求继续投入主动作，不能只等待相同数量的全场轮次就视为完成。
- 续唱及内部连锁不重复收取同一笔起手费用，仍可能有维持费用或动作要求；释放前还须检查目标存活、范围等条件。

### 中断 / 主动取消 / 吟唱惩罚

- 中断是因受击、实际失血、检定或其他条件提前结束，主动取消是施法者自行结束，条件与代价可不同。
- 护盾完全吸收的攻击是否打断取决于能力；血术按实际 HP 损失检查相应中断条件，不是所有受击必定打断。
- 起手费用通常不自动退回，SAN、HP、血液等惩罚及已有武装是否保留，查看角色完整说明。
