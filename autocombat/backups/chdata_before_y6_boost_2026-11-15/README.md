# chData backup before Y6 strength changes

Byte-for-byte copies of the pre-change snapshot, verified against its SHA-256 manifest.

- characters_data.py: complete character data, summon templates, item templates, and loader.
- characters_data_pvp.py: compatibility entry point.
- manifest.json: source location and checksums.

Y6 before this change: original HP 9, one frost stack per hit, instant healing at layer 6.
The backup includes all characters, not just Y6. Current working files were not restored or changed.
