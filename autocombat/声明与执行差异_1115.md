# 规则声明与实际执行差异记录：Y1–Y17、Y60

记录日期：2026-11-15。范围包括 Y1–Y17、Y60 的技能，以及直接关联的阶段、被动、资源和召唤物。按角色编号排列，各角色采用相同的标题层级；跨角色机制和验证记录集中列于文末。保留原文件名，便于既有引用继续使用。

本文记录已发现的声明冲突、执行入口差异和资料表达边界。“声明”指角色数据或旧百科能够表达的规则，不等同于已确认的原始策划意图。每项分别说明可核实的实际行为、百科采用口径及尚待确认的事项；没有完整声明或独立运行用例的地方，不补作推断。

本文用于规则核对与维护，不修改战斗规则。各范围的百科文案均已获得批准，批准文案不代表批准调整战斗行为。本文也不代表对所列角色或全项目完成了完整缺陷审计。来源行号为记录时定位，后续维护应结合函数名核对。

## Y1｜炎焱

### Y1《斗殴精通》：99 回合后继续生效

| 项目 | 核对结果 |
| --- | --- |
| 数据声明 | 自身获得一颗攻击奖励骰，持续 99 回合，技能启用默认延续性。 |
| 实际执行 | 增益倒计时耗尽后转为延续状态，继续参与攻击检定。 |
| 百科口径 | 使用“持续生效”，不将 99 回合列为效果终止时间。该项属于多个声明字段组合后的表达边界。 |

| 项目 | 核对结果 |
| --- | --- |
| 数据声明 | 技能启用默认延续性；攻击效果声明持续 4 回合，每回合伤害为 `2d4+2`。 |

### Y2《召唤使魔》：存续时限的历史差异已修正

| 项目 | 核对结果 |
| --- | --- |

## Y7｜环花暖

### Y7《战意值削弱》：低层概率与旧注释不同，持续时间由专属流程处理

| 项目 | 核对结果 |
| --- | --- |
| 声明冲突 | 数据注释称召唤物战意削弱至 3 层后，削弱判定增加 1 颗奖励骰；效果字段中的基础削弱概率和低层削弱概率均为 50%。效果另声明 `持续回合 = 99`。 |
| 实际概率执行 | `_process_battle_spirit` 直接按百分比随机判定；战意大于 3 层与至多为 3 层时均使用 50%，没有为该判定追加奖励骰。首次处理仅登记初始层数，此后才进行削弱判定。 |
| 实际持续执行 | 登记光环时使用专属效果，`_tick_down_effects` 对该效果跳过倒计时，因此声明的 99 回合不是实际到期时限。来源生命降至零、离场或被隔离时，停止推进削弱；主体压制同时停止，已有战意层数与召唤组攻击惩罚保留。 |
| 百科口径 | 写明召唤物每轮 50% 概率削弱、首次轮首登记层数及来源条件，不将旧注释中的奖励骰或 99 回合写成实际规则。 |

依据：`characters_data.py` 的 `HUANHUANUAN` 注释及战意效果；`battle_engine.py` 的 `_execute_misc_effect`、`_process_battle_spirit`、`_battle_spirit_character_views` 和 `_tick_down_effects`。

### Y14《模式切换·勇气》：伤害骰优势的适用入口不统一

技能声明为行动力降低 2、获得伤害骰优势。普通攻击和主动施放的《重剑·勇气》虽然采用相同基础伤害，但并非同一条伤害执行路径：

- 完整普通攻击在起手时读取攻击者的优势；反击胜出后，不单独重读反击者的勇气优势。
- 快速普通攻击在确定胜方后读取胜方的优势，因此反击者的勇气优势可以生效。
- 主动法术伤害没有额外读取这项优势；主动施放的重剑、三连斩和极限技不会仅因勇气模式而额外掷两次取高。
- 优势用于需要普通掷骰的伤害分支，不再额外提高极难成功的满值伤害或大成功伤害。困难成功自身已有两次取高的结算，也不因此追加第三次掷骰。

已批准百科明确限定上述入口。后续若要统一，需先确定优势应作用于普通攻击、反击、主动法术中的哪些类别，而不是只调整其中一个伤害函数。

依据：`characters_data.py` 中 Y14《模式切换·勇气》；`battle_engine.py:8129` 的完整攻击优势读取、`:8393` 附近的胜方伤害分支、`:10494` 的快速胜方优势读取，以及 `:6277` 的 `_apply_spell_damage`。

## 共通机制与核对依据

### 攻击射程覆盖与几何范围

`characters_data.py:378` 的 `GLOBAL_RANGE_OVERRIDE = 1` 使经 `battle_engine.py:543` 的 `_get_attack_range` 查询的攻击射程返回 99 格。原始射程仍保留在战斗数据中；领域半径、治疗范围和传送距离不能一并改成 99 格。《光速救援》的 8 格未被执行属于独立问题。

Y9–Y12 的批准百科使用实际覆盖后的攻击射程；Y13–Y16 的批准百科同时保留原始射程并注明覆盖值。Y17 的定向矩形、战争半径和血武器普通攻击射程有各自的计算路径，应分别核对，不能据此删除全部基础射程字段。

### Y9、Y11：普通吸血的计算基数

普通吸血入口要求护盾后伤害大于 0 且施法者仍有生命，但回复量使用护盾吸收前的 `dmg_val × 吸血比例` 向下取整，不按目标实际失去生命截断。Y9 两种矛与 Y11《挥动镰刀》不能沿用“实际生命伤害的 25%／65%”描述。Y17《血月斩击》的专属吸取另见对应角色条目，不将普通吸血结论直接套用。

依据：`battle_engine.py:6277` 的 `_apply_spell_damage` 及其中吸血分支。

### 领域时限、成员筛选与效果归属

领域时限、轮首结算次数、是否立即结算、来源存活绑定及范围增益是不同规则。Y9 两个领域和 Y60 雪带采用先递减时限、再处理领域效果的路径；Y60 雪幕绑定来源存活。各项的实际次数与例外见对应角色条目，不按持续回合字段统一推断。
