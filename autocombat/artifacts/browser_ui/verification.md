- React / TypeScript / Vite 前端：大厅、编队、图鉴、棋盘对战、角色详情、召唤组成员、墓地、防御反应、事件回顾、模拟实验室。

- Flask UI 适配层：独立的浏览器房间、公开玩家 ID 与私有会话分离、准备与控制权、观众权限、请求去重、状态版本、SSE 非消耗式事件订阅。

- 单步 AI、服务端播放控制、历史状态快照。召唤物以物理 UID 区分，个人蛋糕可给予指定隐藏组成员。
- 独立模拟子进程、结构化进度、固定种子、CSV 与 JSON 私有导出。
- `start_ui.py` 一键构建启动；`--lan` 开启局域网，`--port` 可调整端口；兼容原有海豹骰入口。

## 使用

已构建的当前版本可直接访问上方 8891 入口。重新启动可用：

```powershell
python start_ui.py --port 8891
# 或选择一个空闲端口，允许局域网设备访问：
python start_ui.py --lan --port 8892
```

同一端口只能运行一个服务。更多操作与美术替换说明见 `frontend/README.md`。
