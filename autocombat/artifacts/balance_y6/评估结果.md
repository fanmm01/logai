# 雪人冰冻重构评估

已实现冰冻值、雪带替换及35 HP召唤物“堆雪人”。最终配置启用跨循环叠加：不叠加版平均11.6胜，低于36胜，按用户指定的条件切换。评估期间外部将雪人基础HP从7改为9，并将雪之法杖的附带攻击替换为1d8＋4护盾、持续5轮；这两项修改均保留。包含这些更新的冻结快照10届预赛平均 **16.7胜／82场**，仍低于36—43胜，未继续修改其他数值。


## 补充机制诊断

在外部修改之前的HP7版本上固定赛季状态50，对16名其他角色各跑3场，共48场。仅2场达到第10层，最高17层。跨循环第2、3层减益通常来不及发挥，这是两种配置胜场没有变化的一个可能原因；这项诊断不替代正式预赛，也不能保证后续随机种子的结果相同。逐场记录见 [诊断数据](frost_diagnostic.json)。
