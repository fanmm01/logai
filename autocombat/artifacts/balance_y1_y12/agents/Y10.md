# Y10 春晌 平衡方案（修订稿·未实施）

## 基线前提（用户确认）
1. **已确认缺陷**：藤蔓死亡后，春晌本体仍可能保持"不可指定"，导致对手无法选中。该问题正由 peer 修复，本方案不自行实施、不代改代码。
2. 现有全部预赛（5043场）及 balanced/官方冻结复核，**均不能视为包含该未来修复**；修复前后数据不可混用。
3. 因此旧 1v1 63.0%、超时 35.8%、固定3v3 70.1% 等只能作为"修复前对照基线"，**不得归因于设计数值**，也不据此先砍群疗或保护。
4. **默认 P0＝先修"不可指定与存活藤蔓联动"，复跑后再定平衡**；下文四项数值调整全部延后为条件触发的备选。

## 定位
春晌是"群体护盾/治疗＋藤蔓不可指定保护＋蜂鸟群"的守护辅助，自身无伤害法术，仅普攻 1d6+1d4。战斗 HP 不是卡面 10：`.hs` 变身 `battle_engine.py:2467` 得 10×(5+7)=120、MP14×5.5=77，probe 的 hp120/mp77 可印证；勿用原始10HP作战斗HP。

## 机制代码行
- `characters_data.py:863-892`：屏障9MP/2d6/5回合，治疗3MP/1d4+2，藤蔓4MP×1/标称5回合，蜂鸟6MP/1d4/标称99回合。`:872` 的 `不可指定:1` 与 `不可指定召唤物:'藤蔓'` 是保护链入口。
- `battle_engine.py:1670-1700` `_is_untargetable`：本意是"owner 存在存活同名藤蔓（非三合一）才不可指定"，`:1687` 已按 `_get_combat_hp>0` 过滤；但藤蔓作为召唤组成员时，死亡清理、组代表切换与隐藏成员 HP 槽可能出现残留，实际表现为藤蔓死后仍保护。这正是 peer 修复点，修复前不要假设该过滤已可靠。
- `:3050-3063` `_enemy_targets` 同样排除不可指定；领域 DOT 循环按坐标/客体筛选（`:6740` 附近）不查不可指定，AOE 按原规则仍可命中——修复验收须保留此行为。
- 召唤寿命另有独立缺陷：`:3729-3819` 只创建召唤，从不写入"持续回合"，`:4799` 过期分支为死路径；藤蔓5回合、蜂鸟99回合均未生效。它不属于本次 peer 修复范围，**不得与不可指定修复捆绑**。
- 行动经济：同模板共享1先攻槽与1主动池（`:1217-1266`），每次组动作全体存活成员各打一次；蜂鸟 MOV11+飞行8=19→4主动/组，N只蜂鸟每回合最多4N击。藤蔓永久禁锢（`:6462-6473`）本为固定炮台，但 `characters_data.py:372` 的 `GLOBAL_RANGE_OVERRIDE=1` 使射程全变99，属全局调试开关，不可擅动。
- AI：`ai_battle.py:518-540` 召唤列表第一为藤蔓，故优先藤蔓；同名召唤封锁不覆盖召唤，1藤蔓在场仍会召第2只；`ai_trainer.py:157-201` 对 T3 拆召唤给0.55惩罚，低估拆藤蔓价值；`:1038` 训练目标已与不可指定过滤一致。

## P0 修复验收（先做，不调数值）
必须同时满足：
1. 藤蔓死亡后，当次目标解析起本体即可被单体指定并命中（无残留保护）。
2. 场上仍有第二只存活藤蔓时，本体仍不可指定。
3. 蜂鸟存活不触发保护。
4. AOE/领域按原规则命中春晌，不因不可指定被豁免。
5. 回归：Y12 三合一/召唤、Y6 雪带等无行为变化；修复不改藤蔓 HP、数量、动作与蜂鸟动作经济。
复跑协议：season50、当前 weights、每场独立 AI、同对手表；至少 1v1 246场、均衡2v2/3v3 各160场、Y10+Y6 246场，记录 Wilson 区间、超时率、决胜局胜率与对位矩阵。只有复跑后仍偏强/仍超时，才进入备选。

## 备选参数（条件触发，逐项、禁止同时削保护）
1. **P1 藤蔓"5回合"真正生效**：触发＝修复后 1v1 超时仍>30% 或 Y10+Y6 超时仍>40%。
2. **P1 蜂鸟组动作封顶2主动/组**（旧4）：触发＝修复后均衡2v2/3v3 仍>55% 且 probe 召唤伤害占比过高。
3. **P2 藤蔓 `max_simultaneous` 2→1**：触发＝P1后仍靠双藤蔓续保护、保护覆盖回合占比>50%。
4. **P3 屏障持续5→3回合**：仅当以上后单挑决胜胜率仍>60% 且超时<25%（即真正终结过强）才启用；治疗术不动。
每次只改一项，改后同协议复跑；AI 侧优先做"已有存活藤蔓不重召"与"拆藤蔓 T3 惩罚修正"，属非数值、风险最低。

## 预期风险与回滚
修复本身可能使 Y10 对 Y4/Y3 的17/21、16/21 明显回落，若修复后决胜局<30% 或均衡团战<45%，说明旧数据主要被缺陷放大，应停止任何数值削弱。蜂鸟动作上限会影响 X1 等共享模板角色；AI 拆召唤奖励可能波及 Y6/Y12。回滚按 P3→P2→P1 逐档，一次一档，保留 probe 与修复前基线对照。
