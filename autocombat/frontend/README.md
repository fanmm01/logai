# 星序 · 浏览器战术室

明亮卡牌风的 autocombat 界面，连接原有 CoC 战斗引擎。角色图鉴自动读取当前角色数据，不要求角色立绘。

## 启动

在项目根目录运行：

```powershell
pip install flask
python start_ui.py
```

浏览器访问 `http://127.0.0.1:8889/ui/`。首次构建需要 Node.js 20.19+ 或 22.12+ 以及 npm；之后 Python 服务提供构建后的静态文件，无需常驻 Node 服务。

局域网多人使用：

```powershell
python start_ui.py --lan
```

好友须通过 `http://房主局域网IP:8889/ui/` 打开页面，然后输入房间码。创建时选择“局域网房间”，分配角色、等待玩家准备后开始；也可作为观众加入。若系统防火墙阻止连接，请由使用者按自己的网络设置允许该服务。

手动构建与原入口兼容：

```powershell
cd frontend
npm ci
npm run build
cd ..
python merge_backend.py
python autocombat_backend.py --host 127.0.0.1 --port 8889
```

开发时先启动 Python 后端（8889），再在 frontend 运行 `npm run dev`。代理会转发 `/api` 并设置同源 Origin；界面默认路径为 `/ui/`。正常使用推荐 Python 同源入口。

## 功能

- 大厅、编队、角色图鉴，内置角色 SVG 徽记与可替换卡面。
- 本地控制双方；每角色可选择 AI；支持双方同编号的镜像对局。
- 局域网房间、房主分配、玩家准备、观众权限、离开后房主接管。
- 棋盘与先攻顺序、主／附动作、MP／SAN、领域、状态、物品、召唤组与墓地。
- 技能目标与移动范围提示；确认前运行隔离副本预览，保留真实资源与随机状态。
- 待反应状态可刷新恢复，后续效果继续由原引擎处理。
- AI 播放、暂停、单步、1×／2×／4×；事件时间线与战后回顾。
- 独立子进程批量模拟，含种子、场数、赛季状态、结构化进度与 CSV／JSON 导出。
- 浏览器刷新及 SSE 断线恢复；重复请求去重、过期版本拒绝、房间身份验证。

## 交互

1. 编队后创建演习，在准备阶段选择己方角色，可调整站位。
2. 开始后点击技能，再点击高亮目标；也可选择“使用默认目标”。
3. 移动时高亮可达格；点击后确认。非法行动不会扣动作。
4. 受到攻击时用反应面板选择闪避、反击或格挡；不可用的方式不会出现。
5. 复活技能从“墓地”页选择合法对象。召唤组可在左侧选择成员展开查看。
6. 左侧角色用于选中与指定目标；底部操作始终属于当前行动角色。
7. 时间线查看历史时禁止提交战斗动作；点击“回到实时”恢复。

## 自定义美术

在 `public/portraits/` 放置 `Y1.webp` 等竖版图片、`Y1-avatar.webp` 等头像，再重新构建。没有图片时使用统一配色的徽记。推荐 3:4 竖版立绘与方形头像。界面设置可关闭动效。

## 边界与运行说明

房间、历史和任务保存在内存；服务重启后需要创建新对局。每房间保留最近 1500 个事件，过旧的订阅会自动重新拉取快照；12 小时无访问的房间清理。AI 推进失败会暂停并记录错误，房主可单步重试或接管角色。暂停影响后续 AI 步骤，已经提交的原子动作会完成。

面向本地与可信局域网；无公网账号、锦标赛淘汰树或训练管理。小屏按纵向面板排列，不需要横向滚动整个页面。界面不更改角色平衡数据。

原海豹骰对局仍走原接口；UI 房间禁止绕过会话调用旧战斗接口。新增适配层位于 `ui_server.py`；服务端修改源文件后运行 `merge_backend.py`，不要只编辑生成的集成后端。分发 UI 时需要同时携带适配层、模拟 worker、模拟相关源文件和 `frontend/dist/`。
