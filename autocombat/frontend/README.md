# 星序 · 浏览器战术室

明亮卡牌风的 autocombat 界面，连接原有 CoC 战斗引擎。角色图鉴自动读取当前角色数据，不要求角色立绘。

## 启动

在项目根目录运行：

```powershell
pip install flask
python start_ui.py
```

浏览器访问 `http://127.0.0.1:8889/ui/`。首次构建需要 Node.js 20.19+ 或 22.12+ 以及 npm；之后 Python 服务提供构建后的静态文件，无需常驻 Node 服务。

局域网多人使用：

```powershell
python start_ui.py --lan
```

好友须通过 `http://房主局域网IP:8889/ui/` 打开页面，然后输入房间码。创建时选择“局域网房间”，分配角色、等待玩家准备后开始；也可作为观众加入。若系统防火墙阻止连接，请由使用者按自己的网络设置允许该服务。

手动构建与原入口兼容：

```powershell
cd frontend
npm ci
npm run build
cd ..
python merge_backend.py
python autocombat_backend.py --host 127.0.0.1 --port 8889
```

开发时先启动 Python 后端（8889），再在 frontend 运行 `npm run dev`。代理会转发 `/api` 并设置同源 Origin；界面默认路径为 `/ui/`。正常使用推荐 Python 同源入口。

## 功能

- 大厅、编队、角色图鉴，内置角色 SVG 徽记与可替换卡面。
- 本地控制双方；每角色可选择 AI；支持双方同编号的镜像对局。
- 局域网房间、房主分配、玩家准备、观众权限、离开后房主接管。
- 棋盘与先攻顺序、主／附动作、MP／SAN、领域、状态、物品、召唤组与墓地。
- 技能目标与移动范围提示；确认前运行隔离副本预览，保留真实资源与随机状态。
- 待反应状态可刷新恢复，后续效果继续由原引擎处理。
- AI 播放、暂停、单步、1×／2×／4×；事件时间线与战后回顾。
- 独立子进程批量模拟，含种子、场数、赛季状态、结构化进度与 CSV／JSON 导出。
- 浏览器刷新及 SSE 断线恢复；重复请求去重、过期版本拒绝、房间身份验证。

## 交互

1. 编队后创建演习，在准备阶段选择己方角色，可调整站位。
2. 开始后点击技能，再点击高亮目标；也可选择“使用默认目标”。
3. 移动时高亮可达格；点击后确认。非法行动不会扣动作。
4. 受到攻击时用反应面板选择闪避、反击或格挡；不可用的方式不会出现。
5. 复活技能从“墓地”页选择合法对象。召唤组可在左侧选择成员展开查看。
6. 左侧角色用于选中与指定目标；底部操作始终属于当前行动角色。
7. 时间线查看历史时禁止提交战斗动作；点击“回到实时”恢复。

## 自定义美术

在 `public/portraits/` 放置 `Y1.webp` 等竖版图片、`Y1-avatar.webp` 等头像，再重新构建。没有图片时使用统一配色的徽记。推荐 3:4 竖版立绘与方形头像。界面设置可关闭动效。

## 边界与运行说明

普通战斗房间和时间线保存在内存，服务重启后需重建普通对局；模拟任务记录和锦标赛进度持久保存在 `.ui-runtime/browser.sqlite3`。赛事重启后暂停，已完成赛果保留，未完成场次从场初重开。每房间保留最近 1500 个事件，过旧的订阅会自动重新拉取快照；12 小时无访问的房间清理。AI 推进失败会暂停并记录错误，房主可单步重试或接管角色。暂停影响后续 AI 步骤，已经提交的原子动作会完成。

面向本地与可信局域网，无公网账号。角色编辑、备份恢复和训练仅向本机开放。角色管理的“保存”会修改 `characters_data.py`；新对局使用更新后的数据，已有对局和任务使用固定的数据与权重版本。小屏按纵向面板排列，矩阵和赛图可在各自面板内横向滚动。

原海豹骰对局仍走原接口；UI 房间禁止绕过会话调用旧战斗接口。新增适配层位于 `ui_server.py`；服务端修改源文件后运行 `merge_backend.py`，不要只编辑生成的集成后端。分发 UI 时需要同时携带适配层、模拟 worker、模拟相关源文件和 `frontend/dist/`。

## 统一数据与角色管理

`characters_data.py` 是唯一数据源，PvP 文件及训练脚本仅保留兼容入口。当前启用角色保持不变；未启用定义不会被自动启用。编辑器按属性—值展示角色、技能和效果，支持增删改、模板管理与下拉选项。点击“保存”先验证、备份，再原子替换源文件；外部修改会触发版本冲突，需重新读取。

“全局设置”保留基础版的 `GLOBAL_RANGE_OVERRIDE=1`，即攻击射程覆盖为 99。可显式关闭；领域半径不受此开关影响。效果类型、明确射程、随机目标和持续骰式会完整保留，列出技能时不会掷持续骰。

备份位于 `.ui-runtime/backups/`，可手动创建、下载和恢复。保存、恢复、权重替换前自动备份；恢复前校验清单。角色删除后，引用它的预设会显示失效。重新训练使用默认 50 代 × 每代 100 场及召唤训练配置，在隔离子进程执行，成功后替换 `ai_weights.json`，失败保留旧权重。

## 自动反应与 mode2 操作

战场常驻两个独立控件：“开启自动反应”“停止自动反应”。选择自己控制的单位、反应方式和次数后开启，界面实时显示剩余次数。非本人回合也可停止；当前单次结算完成，后续反应转手动，不撤销或重复结算。无可用的预设方式时停止并提示。关闭不受普通战斗按钮忙碌和战况版本变化限制，刷新不会重新开启。

控制角色不会自动控制召唤物；召唤物默认 AI，可在房间面板独立接管整组。控制权依附稳定召唤组，不因代表更换重置。

“mode2 操作与战斗管理”提供自定义技能值、伤害骰、奖惩骰、攻击次数、贯穿、致死、随机目标、公布时机、变身、持续效果结束、物品使用／转交、战斗检查点、属性调整及 AI 策略。房间分配同时用于代理操控。海豹骰可用 `.e stop [角色编号]` 或 `.e 停止 [角色编号]` 清除预设；`.sN end` 结束该技能的持续效果。

战斗记录直接呈现完整行动与检定细节，按回合、角色、技能及反应展开，保留缩进和结果，不再截成三行摘要。

## 模拟与锦标赛

模拟页支持 single、verbose、table、prelim，种子和赛季状态留空为随机；矩阵支持预设或自选小队。可取消模拟，下载 CSV／JSON；输出位于各任务独立目录，不覆盖 CLI 报告。

锦标赛每个实例只属于一种赛制。常规赛按原积分／超时／排序规则更新排名，结束后生成赛图并在附加赛前自动暂停。季后赛支持模拟本轮、本系列赛、本场、逐回合本场、进场观战、逐回合季后赛及快速模拟全部季后赛。本轮仅推进所选赛制、所选阶段；本系列赛和本场不影响其他系列赛。逐回合播放可暂停／继续。

赛图下方从上到下为“逐回合血量变化”和“逐回合战斗记录”。血量变化直接复用 ai_battle 的回合初显示，包含原有的召唤物血量汇总规则。普通模拟不传输逐步战斗记录，单场完成后一次性提供完整血量回放；逐回合模拟动态更新两栏。回放按场次保存，可从场次列表重新查看，逐回合模拟的详细记录也会保留。升级前已经完成且未记录回放的场次不在回放列表中。

进场观战使用当前棋盘，允许接管，结果只回写一次并标记人工参与；反复进入仍是同一场。暂停观战后可返回同一棋盘继续，不能同时启动另一份比赛。赛事采用原 Bo5 附加赛及 Bo7 淘汰赛；随机种子、源数据、权重和队表均固定在创建时。

锦标赛战后按钮为“下一场”：系列赛未结束时继续当前系列赛；结束后进入赛图顺序中下一组可进行的系列赛。重复点击返回同一个后继房间。全部系列赛结束后按钮停用；普通演习仍保留“再来一场”。

分发需携带全部 `ui_*.py`、原引擎及模拟源文件、统一数据／权重与 `frontend/dist/`。修改服务源代码后重新执行 `python start_ui.py`。
