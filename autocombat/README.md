# 半自动战斗扩展 (autocombat) v1.1.0

CoC 魔法少女半自动战斗规则 Sealdice 插件。前置：logutil v5.0+、coc7 扩展。

---

## 一、快速开始

### 1. 启用模板

```
.set autocombat      // 或 .set mg / .set 魔法少女
```

注册别名：`伤害值↔dmg` `伤害贯穿↔pen` `致死骰↔leth` `魔力↔mp` `等级↔level` 等。

### 2. 设等级（首次必做）

```
.st 等级 3
```

变身倍率依等级计算，默认 1。

### 3. 录入法术

用 Excel 法术表的导入区生成 `.st` 命令，复制到骰子机器人一次性录入全部属性和法术。详见第七节。

### 4. 变身（自动开启战斗同步）

```
.hs
```

效果：HP×(5+等级)、MP×(2+0.5×等级)、APP+60(≤80)、全部战斗技能+20(≤80)、体格+1、MOV+2、自动执行 `.btastart`。

### 5. 攻击

```
.bta 斗殴 @目标                  // 近战，等待反应
.bta 手枪 1d8 @目标              // 远程，直接结算
.bta 3# 斗殴 @目标               // 连击3次
```

### 6. 反应（被近战攻击方）

```
.e d             // 闪避
.e c             // 反击（自动最高近战）
.e c 剑 1d8      // 指定技能与伤害
```

### 7. 结束

```
.btaend          // 战斗后同步
.unh             // 解除变身（自动 .btaend + SC/CON检定 + 升级结算）
```

## 二、模式切换

| 指令 | 说明 |
|:---|:---|
| `.setab 0` | 最小自动化（单次攻击-反应-结算 + 变身/解除） |
| `.setab 1` | 完全自动化（地图、回合制、法术引擎） |
| `.setrestim 0` | 攻击时立即公布检定结果（默认） |
| `.setrestim 1` | 反应动作后才一并公布双方检定结果 |

## 三、攻击指令

### 3.1 语法

```
.bta <技能> [伤害骰] [贯穿0/1] [致死0/1] [n#] @目标1 [/a/b/c] [@目标2 ...]
```

### 3.2 参数

| 参数 | 说明 | 示例 |
|:---|:---|:---|
| 技能 | 技能名、数值、`技能+N`、`技能N` | `斗殴` `50` `斗殴+10` `斗殴50` |
| 伤害骰 | XdY 表达式，默认读角色卡 `伤害值` | `1d6` `2d6+1d4` |
| 贯穿 | 0/1，默认读角色卡 `伤害贯穿` | `1` |
| 致死 | 0/1，默认读角色卡 `致死骰` | `0` |
| n# | 连击次数（上限 20） | `3#` |
| @目标 | 必须 @ 至少一个目标 | `@张诗遥` |
| /a/b/c | 目标控制多角色时的子编号 | `/a` |

### 3.3 变体

`.btab`(奖励骰) `.btap`(惩罚骰) `.btab2/.btab3` `.btap2/.btap3`

### 3.4 全局后缀

```
.bta asa 斗殴 1d6 @目标      // 所有技能查斗殴a/伤害值a/贯穿a/致死a
.bta asb 斗殴 @目标           // 后缀b
```

### 3.5 示例

```
.bta 斗殴 @张诗遥                              // 基础攻击
.bta 斗殴a 1d6 1 0 @张诗遥                     // 指定后缀+伤害+贯穿+致死
.bta 3# 斗殴 @张诗遥                            // 连击3次
.bta 斗殴 @张诗遥 /a @李四 /b                   // 多目标，各配子目标
.bta asa 斗殴 1d6 @张诗遥                       // 全局后缀a
.bta 1d6 @张诗遥                                // 仅伤害骰→自动最高近战
.bta @张诗遥                                    // 全省略→最高近战+默认伤害
.bta 50 @张诗遥                                 // 纯数字=技能值50
```

## 四、反应指令

### 4.1 语法

```
.e 闪避           // 或 .e d
.e 闪避a          // 使用后缀a的闪避值（或 .e d a）
.e 反击 [技能] [伤害骰] [贯穿gc/ngc] [致死]
.e c [技能] [伤害骰] [贯穿gc/ngc] [致死]
.e c 70 3d6 gc 1  // 技能值70 + 伤害3d6 + 贯穿 + 致死
.e c 斗殴+10      // 技能值=斗殴+10
.e s1             // 法术1作反应（法术需时机=反应）
```

### 4.2 变体

`.eb`(奖励骰) `.ep`(惩罚骰) `.eb2/.eb3` `.ep2/.ep3`

### 4.3 反应规则

| 反应 | 效果 |
|:---|:---|
| 闪避 | 每高于成功一级→攻击方有效等级-1。大失败→攻击方+1（原失败则+2→成功） |
| 反击 | 默认最高近战技能。对抗胜利后按自身成功等级计算伤害 |
| 技能反应 | `.e s<N>` 释放时机含"反应"的法术 |

- 多次攻击时**每次独立掷反应骰**
- 攻击方大失败时反击有效等级+1
- 角色卡 `可反应=0` 时禁止闪避/反击

## 五、变身与解除

### 5.1 变身 `.hs`

```
HP   = HP_original × (5 + level)
MP   = MP_original × (2 + 0.5×level)
APP  = min(APP_original + 60, 80)
全部战斗技能 += 20（上限80，仅属性表中有该技能时生效）
Build += 1 → DB 上升一级
MOV  += 2
自动执行 .btastart（战斗同步+初始化战斗HP）
```

### 5.2 解除变身 `.unh`

- HP = min(ceil(当前HP/(等级+5)) + 2, 原HP上限)
- MP = min(当前MP, 原MP上限)
- 若使用了 >2 次法术或进行了战斗 → 触发 SC 与 CON 检定
- `.setab 1` 模式下自动结算升级
- 自动执行 `.btaend`

### 5.3 SC/CON 层级

| SAN | SC(成功/失败) | CON(成功/失败) |
|:---|:---|:---|
| ≥30 | 0 / 1d5 | 0 / 1d3 |
| <30 | 1 / 1d6 | 0 / 1d3+1 |
| <20 | 1d3 / 1d8 | 1d3 / 1d6 |
| <CM 时 | 损失减半 | 损失减半 |

## 六、伤害计算

### 6.1 按成功等级

| 胜方等级 | 伤害 |
|:---|:---|
| 成功 | 正常掷伤害骰（有优势/劣势标记则取二大/小） |
| 困难成功 | 伤害骰优势（掷两次取大） |
| 极难成功 | 不贯穿→满值。贯穿→满值+掷伤害骰 |
| 大成功(出目1) | 满值×2 |
| 大成功(出目2-5) | 不贯穿→满值+掷伤害骰。贯穿→满值×2 |

### 6.2 致死骰

伤害期望 > 6 时触发。掷 1d(当前HP×2)，出目 ≤ 伤害期望 → 立即死亡/丧失战斗力。

## 十一、升级与熟练度

### 11.1 等级

- 有效变身次数 ∈ {1,3,6,10,15,…} → 等级 +1
- 等级 4,8,12… → 解锁【深层魔法】
- 等级 2,6,10… → 解锁【浅层魔法】
- 任意升级 → 选一个魔法 +30 熟练度
- `.setab 0` 模式下不自动结算升级

### 11.2 熟练度获取

| 来源 | 数值 |
|:---|:---|
| 升级时选中 | +30 |
| 法术大成功 / 成功终结 | +30 |
| 战斗中使用了该法术 | +1d20 |

### 11.3 熟练度阈值（每级择一）

| 熟练度 | 可选效果 |
|:---|:---|
| 30 | 伤害骰升档(d4→d6→d8→d10→d12) **或** 吟唱-1/4 **或** 持续+1/3 **或** 致死+2 **或** 半径+1格 |
| 60 | 同上再择一 |
| 90 | 同上再择一 |
| 100 | 深化（升级为深层模式，由 KP 设计） |

升级效果通过重新 `.st` 录卡实现（系统仅追踪，不自动修改属性）。

## 十五、行动力/移动力/射程系统 (v1.1)

### 15.1 基本概念

- **行动力 (Action Power)**：进行反应与避让的能力。默认值 = **MOV**。
- **移动力 (Move Power)**：一回合内可移动的最大距离（Chebyshev 距离）。默认值 = 行动力 = MOV。
- 两者一般相等（初始默认值均为 8）。若角色有属性 `分离行动力移动力=1`，则可分别设置 `行动力` 与 `移动力`。

### 15.2 射程

每个非领域类型的攻击都具有"射程"参数：
- **近战攻击**：射程 = 2（斗殴、剑、鞭等）
- **远程攻击**：射程 = 99（火球、雪球、星闪攻击等）
- 法术效果可通过 `'射程': N` 显式声明，未声明默认为 2

### 15.3 攻击前移动

1. 检查目标是否在 (移动力 + 射程) 的 Chebyshev 距离内
2. 若在射程内：直接攻击
3. 若在 (射程+移动力) 内：消耗移动力移动至射程位置，然后攻击
4. 若超出范围：移动力全部消耗靠近目标，**不消耗主行动次数**，攻击失败

### 15.4 攻击后退回

攻击结束后，尝试消耗剩余移动力退回原始位置。总移动力消耗上限 = 移动力值，每回合开始时重置。

### 15.5 行动力优势

- 若进攻方行动力 ≥ 防守方行动力 + 5，且进攻方行动力 > 10：进攻方获得 **1 奖励骰**
- 否则若防守方行动力 > 10：防守方所有反应动作获得 **1 惩罚骰**

### 15.6 Zone 属性削减

Zone 效果（type=8）现在正确应用 `属性削减`（如 `'行动力-5'`）：zone 内角色每回合受到指定属性的 debuff（最低降至 1）。
