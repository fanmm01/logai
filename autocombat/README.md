# autocombat — CoC魔法少女半自动战斗系统 v1.3.0

SealDice（海豹骰）插件，提供 CoC 魔法少女半自动战斗规则支持。

## 环境要求

- **SealDice** 1.4.0+
- **coc7** 扩展
- **loganalyser/logutil** v5.0+
- **Python** 3.10+
- **Flask**：`pip install flask`

## 快速开始

### 1. 启动后端

```bash
cd autocombat
pip install flask
python autocombat_backend.py
```

后端默认监听 `http://0.0.0.0:8889`。也可使用 `--port` 指定端口。

### 2. 加载 JS 插件

将 `autocombat.js` 放入 SealDice 的插件目录，重载插件。

### 3. 启用规则

在群内发送：
```
.set autocombat
```

或使用别名：`.set mg` / `.set magicgirl`

## 战斗模拟 (.sim)

`.sim` 命令运行快速战斗模拟，支持两种模式。所有参数与 `python sim.py` 完全一致，但 `--` 开头的长参数需去掉双横线（如 `--mode` → `mode`）。

### 单场模式（默认）

```
.sim Y5 vs Y1 -n 100 -m 10x10 -s 12345 season 80
.sim Y5+Y6+Y7+Y8 vs Y9+Y12 -n 200
```

多角色用 `+` 连接。输出双方胜率统计和平均回合数。

### 详细回放模式（verbose）

```
.sim Y5 vs Y1 verbose -s 12345
.sim Y3+Y9 vs Y1+Y7+Y8 verbose
```

仅模拟 1 场，输出每回合完整的掷骰、技能、伤害等细节。

### 胜率矩阵模式（table）

```
.sim mode table format 1v1 -n 50
.sim mode table format 2v2 teams "Y5+Y6,Y7+Y8,Y1+Y2" -n 30
.sim mode table format 3v3 teams "Y1+Y10+Y11,Y2+Y5+Y10" -n 20
```

输出 N×N 胜率矩阵表格（ASCII）、CSV/JSON 文件，以及平均积分排名和团队贡献率排行榜。

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `TEAM_A vs TEAM_B` | 对战双方（多角色用 `+` 连接） | 必填 |
| `-n N` | 战斗场数 | 100（single）/ 50（table） |
| `-m WxH` | 地图尺寸 | 10x10 |
| `-s SEED` | 随机种子 | 随机 |
| `season S` | 赛季状态 0-100（越高AI越强） | 随机 |
| `verbose` | 详细回放模式（仅1场） | 关闭 |
| `mode table` | 切换为胜率矩阵模式 | — |
| `format FMT` | 矩阵赛制：`1v1` / `2v2` / `3v3` | 1v1 |
| `teams "..."` | 2v2/3v3 自定义队伍（逗号分隔） | — |

## 代骰（代理操控）

v1.3.0 起，所有 setab=2 命令支持代骰：在命令后 `@另一玩家`，即可代替该玩家操控其绑定的角色。

**示例**：
```
.bta 斗殴 @玩家B       → 以玩家B的绑定角色进行攻击
.e d @玩家B            → 以玩家B的绑定角色闪避
.s3 @玩家B             → 以玩家B的绑定角色使用技能3
.i end @玩家B          → 以玩家B的绑定角色结束回合
.as Y1 @玩家B          → 为玩家B绑定Y1角色
```

## 训练系统

`.train` 命令触发一次 PVP AI 训练：
- 使用 Q-Learning 算法训练 AI 策略
- 训练在后台运行（预计需数分钟）
- 训练完成后自动重载 Q 表（`ai_weights_pvp.json`）
- 可通过 `.jour` 验证训练效果

---

## 锦标赛系统

`.jour` 命令运行 AI 锦标赛：
- **赛制**：单循环预赛（积分制）+ 8强淘汰赛（Bo7）
- **三种模式**：1v1、2v2、3v3（默认全部）
- **输出格式**：由 `pictmode` 配置决定（0=文字, 1=图片）
- **输出内容**：积分表 → 签表 → 淘汰赛赛果 → 半决赛起详细过程 → 最终结果
- **停止**：`.jour stop` 立即停止当前锦标赛进程

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| PvP战斗后端地址 | string | http://127.0.0.1:8889 | Python 后端地址 |
| pictmode | int | 1 | 战斗消息图片模式（0=文本, 1=图片） |
| AI暂停时长下限 | int | 1 | AI回合间暂停下限（秒） |
| AI暂停时长上限 | int | 5 | AI回合间暂停上限（秒） |
| 失败攻击允许反应 | int | 1 | 失败攻击是否允许防御方反应 |
| 自动战斗模式 | int | 1 | 默认战斗模式 |
| 检定公布时机 | int | 0 | 检定结果公布时机 |
| AI回合延迟 | bool | true | AI回合间是否随机延迟 |

## 添加新角色

在 `characters_data_pvp.py` 中添加新角色，需要按以下步骤操作。

### 1. 角色数据定义

在 `ALL_CHARACTERS` 列表末尾添加新角色的 `chData` 字典。参考现有角色（如 Y1 炎焱）的结构：

```python
{
    'name': '角色名',          # 显示名称
    'serial': 'Y14',           # 唯一序号
    'pre_transformed': False,  # 是否初始即变身状态
    'attrs': {                 # 整数/布尔属性
        '等级': 3,
        '体力': 12, '体力上限': 12,
        '魔力': 14, '魔力上限': 14,
        '敏捷': 60, '闪避': 25,
        '斗殴': 50,
        '行动力': 3, '回合行动数': 1,
        '力量': 50, '体质': 50, '体型': 50,
        '外貌': 50, '教育': 50, '智力': 50, '意志': 50, '幸运': 50,
        '伤害贯穿': 0, '可反击': 1, '状态': 60,
        '体格': 0, '可格挡': 0,
        # ... 其他特殊属性
    },
    'str_attrs': {             # 字符串属性
        '伤害值': '2d6',       # 必填：基础伤害骰
        '伤害值a': '1d8+2',    # 可选：变身前的变体a
        '伤害值b': '2d8',      # 可选：变身前的变体b
    },
    'inventory': [             # 物品栏
        {'item': '蛋糕HP', 'count': 3},
        {'item': '蛋糕MP', 'count': 3},
    ],
    'spells': [                # 技能列表
        {
            'name': '技能名',
            'timing': '2',     # 1=被动 2=主动 3=附加 '23'=主动+附加
            'category': 1,     # 1=攻击 2=护盾 3=治疗 4=增益 5=召唤 8=zone
            'phase': 0,        # 0=通用 1=阶段1 2=阶段2
            '消耗mp': 4,
            '消耗san': 0,
            'effects': [
                {
                    'type': 1,           # 效果类型（见下方）
                    '客体': 4,           # 1=自身 3=友方 4=敌方 5=全体敌方
                    '伤害骰': '3d6',
                    '成功率': 70,        # 技能成功率
                    '可闪避性': 1,       # 1=可闪避 0=不可
                    # ... 更多效果参数
                },
            ],
        },
    ],
}
```

### 2. 技能效果类型

| type | 说明 | 关键字段 |
|------|------|----------|
| 1 | 伤害 | `伤害骰`, `成功率`, `可闪避性`, `贯穿` |
| 2 | 护盾 | `护盾值`, `护盾目标` |
| 3 | 治疗 | `回复hp`, `回复mp` |
| 4 | 增益/减益 | `技能加减值`, `属性削减`, `辅助效果` |
| 5 | 召唤 | `召唤物模板`, `召唤个数` |
| 6 | 制造物品 | `制造物`, `制造物计数` |
| 8 | Zone效果 | `zone尺寸`, `zone持续回合`, `zone效果` |
| 9 | 阶段切换 | `切换阶段` |
| 10 | 延迟治疗 | `延迟回合`, `回复hp` |
| 11 | 战斗意志 | `辅助效果值` |

### 3. 召唤物模板

如需新召唤物，在 `SUMMON_TEMPLATES` 字典中添加：

```python
SUMMON_TEMPLATES = {
    # ... 现有模板 ...
    '新召唤物名': {
        'HP': 30, 'MP': 10, 'SAN': 0,
        'STR': 50, 'CON': 50, 'SIZ': 30,
        'DEX': 60, '闪避': 30,
        'MOV': 8, '行动次数': 1,
        'skills': [
            {'name': '攻击', 'val': 50, 'dice': '1d6'},
        ],
    },
}
```

### 4. 物品模板

如需新物品，在 `ITEM_TEMPLATES` 字典中添加：

```python
ITEM_TEMPLATES = {
    # ... 现有模板 ...
    '新物品名': {
        '回复hp': '2d6',       # 可选
        '回复mp': '1d4',       # 可选
        '技能加减值': '斗殴+10',  # 可选：buff效果
        'buff持续回合': 2,
    },
}
```

### 5. 激活新角色

1. **重载后端**：使用 `.chreload` 命令，或重启 Python 后端
2. **验证**：使用 `.sim Y14 vs Y1 -n 10` 快速测试新角色战斗表现
3. **锦标赛**：在 `team_tables.py` 中添加包含新角色的 2v2/3v3 队伍，即可参与 `.jour`
